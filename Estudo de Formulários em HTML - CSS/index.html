Estudo de Formulários em HTML

Praticando formulários, elementos, tipos de input e atributos utilizando HTML e CSS.

1. HTML Forms

O elemento <form> é utilizado para criar um formulário.

Dentro dele podemos adicionar diferentes elementos para receber informações do usuário.

2. Atributos do Formulário

Os atributos do elemento <form> permitem definir diferentes comportamentos para o formulário.

action: Define o endereço que receberá os dados enviados pelo formulário.

3. Elementos de Formulário

Um formulário pode utilizar diferentes elementos para receber informações.

Input

Select

Textarea

Button
