# 📝 Estudo de Formulários em HTML e CSS

Projeto desenvolvido durante meus estudos de **HTML5 e CSS3**, com foco na criação, estruturação, utilização e estilização de formulários.

Este projeto reúne os principais conceitos estudados nos conteúdos de **HTML Forms** da W3Schools.

## 📚 Conteúdos utilizados como referência

- [HTML Forms](https://www.w3schools.com/html/html_forms.asp)
- [HTML Form Attributes](https://www.w3schools.com/html/html_forms_attributes.asp)
- [HTML Form Elements](https://www.w3schools.com/html/html_form_elements.asp)
- [HTML Input Types](https://www.w3schools.com/html/html_form_input_types.asp)
- [HTML Input Attributes](https://www.w3schools.com/html/html_form_attributes.asp)
- [HTML Form Attributes](https://www.w3schools.com/html/html_form_attributes_form.asp)

---

## 🎯 Objetivo

O objetivo deste projeto é compreender como os formulários funcionam em HTML e como diferentes elementos, tipos de entrada e atributos podem ser utilizados para criar interfaces de entrada de dados.

Durante o desenvolvimento foram praticados:

- `<form>`
- `<input>`
- `<label>`
- `<select>`
- `<option>`
- `<textarea>`
- `<button>`
- `type`
- `id`
- `name`
- `value`
- `for`
- `action`
- `method`
- `autocomplete`
- `novalidate`
