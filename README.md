# 💻 Interfaces-PROA

Repositório criado para armazenar meus estudos, exercícios, projetos e atividades desenvolvidos durante minha formação no **Instituto PROA**.

Este repositório representa minha evolução no aprendizado de desenvolvimento de interfaces, reunindo desde os primeiros conceitos de **HTML e CSS** até projetos mais completos desenvolvidos ao longo da formação.


---

## 🎯 Objetivo

O principal objetivo deste repositório é organizar e documentar minha trajetória de aprendizado.

Aqui serão armazenados:

- 📚 Exercícios de estudo
- 🧪 Atividades práticas
- 💻 Projetos desenvolvidos durante as aulas
- 🎨 Estudos de HTML e CSS
- 📝 Anotações e exemplos
- 🚀 Projetos utilizados para praticar novos conceitos

A ideia é manter tudo organizado para acompanhar minha evolução ao longo do curso.
