3. Lista de Definição

As listas de definição são utilizadas para apresentar termos e suas respectivas descrições.

Codar
Termo utilizado informalmente por desenvolvedores para representar o ato de programar ou escrever código.
HTML
Linguagem de marcação utilizada para estruturar o conteúdo de páginas da web.
CSS
Linguagem utilizada para estilizar e definir a aparência dos elementos de uma página web.
