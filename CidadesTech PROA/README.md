# 🌆 10 Cidades Mais Tecnológicas do Estado de São Paulo

Projeto desenvolvido durante meus estudos de **HTML5 e CSS3**, com foco na criação, estruturação e estilização de uma página informativa.

Este projeto foi criado como prática dos conteúdos estudados em HTML e CSS, utilizando como tema as 10 cidades mais tecnológicas do Estado de São Paulo.


---

## 🎯 Objetivo

O objetivo deste projeto é praticar a criação de uma página HTML utilizando diferentes elementos para estruturar e organizar informações.

Durante o desenvolvimento, foram praticados:

- Estrutura básica do HTML
- Hierarquia de títulos
- Parágrafos
- Links
- Imagens
- Elementos semânticos
- `header`
- `main`
- `section`
- `figure`
- `figcaption`
- `footer`
- `time`
- `abbr`
- `cite`
- `q`
- `strong`
- `em`
- `ins`
- Atributos HTML
- Classes
- Organização de conteúdo
- Estilização utilizando CSS
- Responsividade


---

## 🛠️ Tecnologias utilizadas

- **HTML5**
- **CSS3**
- **Visual Studio Code**
